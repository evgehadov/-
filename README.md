#Кодирование Хаффмана

**Визуализация и интерактивная демонстрация алгоритма Хаффмана**

Проект представляет собой полную реализацию алгоритма Хаффмана с красивой визуализацией дерева, таблицей кодов и метриками эффективности.

---

## 🌐 Онлайн-демо (самый простой способ)

Просто открой файл **`index.html`** в любом современном браузере (Chrome, Edge, Firefox, Safari).

**Ничего запускать не нужно** — весь алгоритм работает прямо в браузере на JavaScript.

---

## ✨ Возможности

- **Построение дерева Хаффмана** с подсветкой ветвей 0/1
- **Таблица кодов** с длинами и вероятностями
- **Гистограмма** длин кодов + метрики (энтропия, средняя длина, эффективность, избыточность)
- **Интерактивный ввод** своих символов и вероятностей
- **Готовые примеры** (русский язык, английский, вырожденные случаи)
- **Полная Python-реализация** + юнит-тесты

---

## 📁 Структура проекта

| Файл                | Назначение |
|---------------------|----------|
| `huffman.py`        | Основная реализация алгоритма (узлы, дерево, коды, метрики) |
| `visualization.py`  | Визуализация с помощью matplotlib |
| `tests.py`          | 25 юнит-тестов (можно запустить `python tests.py`) |
| `index.html`        | Полноценный веб-интерфейс (работает автономно) |
